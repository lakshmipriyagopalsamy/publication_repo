# Governing Autonomous Task-to-Action Agents in Enterprise Information Systems

- **Venue:** ACM Transactions on Management Information Systems (TMIS) — Research Commentary track
- **Status:** draft (cover letter and disclosure statement pending)
- **Type:** Research Commentary (~3,900 words, body only)

## Abstract
Proposes treating autonomous task-to-action (TTA) agents as managed organizational roles with a five-stage lifecycle, three governance artifacts (Agent Role Charter, Decision Rights Matrix, Decision Trace Record), and an autonomy control plane architecture, framed as a Research Commentary using an illustrative worked example rather than an empirical study.
