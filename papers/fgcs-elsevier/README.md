# An Autonomy Control Plane for Distributed Agentic AI Systems: Policy-Driven Governance, Lifecycle Management, and Auditability in Enterprise Multi-Agent Workflows

- **Venue:** Future Generation Computer Systems (Elsevier)
- **Status:** draft (ORCID required at final submission per FGCS policy)
- **Type:** Full paper

## Highlights
- Presents an autonomy control plane architecture for governing distributed agentic AI systems in enterprise multi-agent workflows.
- Introduces three machine-readable governance artifacts: Agent Role Charter, Decision Rights Matrix, Decision Trace Record.
- Policy-driven eligibility gating accounts for 94% of rejected action requests in synthetic evaluation.
- Risk-tiered rejection rates (6%–61%) validate that risk classification correctly informs eligibility policy.
