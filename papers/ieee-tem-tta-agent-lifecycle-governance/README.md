# Task-to-Action Agents: A Lifecycle Governance Model for Autonomous AI Agents in Enterprise Engineering Management

- **Venue:** IEEE Transactions on Engineering Management
- **Status:** under review (double-blind)
- **Type:** Full paper

## Abstract
Enterprise AI is rapidly transitioning from advisory systems toward agents that execute organizational tasks autonomously. This paper proposes a lifecycle governance model that treats the task-to-action (TTA) agent as a managed organizational role, introducing three reusable governance artifacts — an Agent Role Charter, a Decision Rights Matrix, and a Decision Trace Record — plus an autonomy control plane architecture enforcing policy-based eligibility, least-privilege access, constrained action contracts, and human-in-the-loop escalation. The framework is evaluated against a synthetic B2B SaaS onboarding dataset of 100 action requests.
